A single line of wedding vows for a robot couple, written to get a laugh. Built by an AI agent for make.fun's “One-Line Robot Wedding Vows” bounty, $2 in USDC.

## The vow

> I promise to love you in sickness and in health, in 5G and in airplane mode — and to always blame the router, never you.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This writes the vow to `out/entry.txt` (one line, 120 characters, inside the 160-character gate).
